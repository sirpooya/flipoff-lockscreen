A decoy, not a vault

The goal is to fool a nosy coworker or sibling for the ten seconds it takes them to reach for your trackpad — not to stop a real attacker.

Your desktop, still live

The shield is transparent, so the real desktop keeps rendering underneath — notifications slide in, videos play, spinners spin. No blur, no lock chrome, no "this Mac is locked" banner. Prefer a still? Frozen mode screenshots every display instead.

Nothing dismisses it

Keys, clicks, scroll, tablet input — all swallowed. Unlike a real screensaver, which quits on any keypress, FlipOff gives way only to your own hotkey or Touch ID. Poke it and the mascot wakes up.

It photographs them

One silent snapshot from the built-in camera, saved to your Downloads folder — fired only on a failed unlock, never on lock, never twice for the same lock. You come back and find out who tried.

What it isn't

Anyone who can power-cycle your Mac, pull the disk, or SSH in is entirely unaffected — FlipOff is a window, not FileVault. Use ⌃⌘Q for actual security. Use FlipOff when you want to leave your screen up and have opinions about who reads it.

Install

Menu-bar only — no Dock icon, no window, no account.

Download and unzip

Drag FlipOff.app into /Applications.

Right-click → Open on first launch

Builds are unsigned and un-notarized, so Gatekeeper objects once. Auto-updates are verified by an EdDSA signature instead of an Apple certificate.

Grant Accessibility

That's the one that matters — it's what lets FlipOff swallow keyboard and trackpad input. Camera is optional and only powers the snoop snapshot; Screen Recording is only needed if you switch the backdrop to Frozen. Deny either and the lock still works.

Hit Cmd+Shift+L

Rebindable in Settings, along with the mascot emoji and the sound.

Build from source

Swift + SwiftUI, no dependencies beyond Sparkle.

# Xcode 26 on macOS 26 — the app icon is an Icon Composer bundle
brew install xcodegen
xcodegen generate
xcodebuild -scheme FlipOff -configuration Debug build
